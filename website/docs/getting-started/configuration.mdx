# Configuration

## Settings file

pi stores settings in `~/.pi/settings.json` (global) and `<cwd>/.pi/settings.json` (project-level). Project settings override global settings.

```json
{
  "defaultModel": "claude-sonnet-4-20250514",
  "defaultProvider": "anthropic",
  "enabledModels": ["claude-sonnet-4-20250514", "gpt-4o"],
  "tuiMode": "fullscreen",
  "toolPermissions": {
    "allowShell": true,
    "allowNetwork": false,
    "allowFileRead": true,
    "allowFileWrite": true
  }
}
```

## Providers

pi supports multiple LLM providers. Each provider has its own API key env var:

| Provider | Env var |
|----------|---------|
| Anthropic | `ANTHROPIC_API_KEY` |
| OpenAI | `OPENAI_API_KEY` |
| Google | `GOOGLE_API_KEY` |
| Groq | `GROQ_API_KEY` |
| OpenRouter | `OPENROUTER_API_KEY` |

## Switching models

In the TUI, press `Ctrl+P` to open the model selector. Select a provider and model. The selection is saved globally.

To set the default model in `settings.json`:

```json
{
  "defaultModel": "claude-sonnet-4-20250514",
  "defaultProvider": "anthropic"
}
```

## Tool permissions

Control what pi can do by editing `toolPermissions` in settings:

```json
{
  "toolPermissions": {
    "allowShell": true,
    "allowNetwork": false,
    "allowFileRead": true,
    "allowFileWrite": true,
    "allowedCommands": ["git", "npm", "bun", "pnpm"],
    "deniedCommands": ["rm -rf /", "format C:"]
  }
}
```

:::warning Shell access
When `allowShell` is `true`, pi can run any command in your `PATH`. Restrict `allowedCommands` to limit what it can execute.
:::
